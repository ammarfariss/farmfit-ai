## Required Before Submission

For each source actually used, record:

- official source name;
- direct source link;
- variables used;
- spatial/temporal resolution where relevant;
- whether data are static, historical, climatological or current;
- any preprocessing performed;
- important uncertainty/limitations;
- licence/terms; and
- whether redistribution is permitted.

The presentation and README must use the same source list as the final code.
